# CLI Student Manager (Rust)

A command-line application for managing and analyzing student scores.

## Features
- Add student scores
- View all scores
- Analyze performance (grade, pass/fail, feedback)
- Calculate statistics (average, highest, lowest)

## Tech Stack
- Rust
- Standard Library (no external crates)

## Application
This project can be used in any scenario involving management of scores.

## How to Run
```bash
cargo run
